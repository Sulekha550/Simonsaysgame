This project is a classic Simon Says memory game developed using HTML, CSS, and JavaScript. The game challenges players to remember and repeat an increasing sequence of colors, helping improve focus and memory skills.

The application features interactive animations, sound/visual feedback, and dynamic level progression handled through JavaScript logic. A clean and responsive UI ensures smooth gameplay across different screen sizes.

This project highlights my understanding of JavaScript game logic, event handling, and DOM manipulation, along with strong fundamentals of front-end web development and user interaction design.
